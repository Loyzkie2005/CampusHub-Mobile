# Synthetic Demo image assets

Illustrative food artwork by [OpenMoji contributors](https://openmoji.org/),
bundled unchanged from [OpenMoji 17.0.0](https://github.com/hfg-gmuend/openmoji/releases/tag/17.0.0).
Graphics license: **CC BY-SA 4.0**, included in `LICENSE.txt`. Original download
URLs and SHA-256 hashes are in `sources.json`; the app registers the credit in
Flutter's license registry when these illustrations are used.

These are demo illustrations, not photographs of actual seller products.
`synthetic_demo_images.dart` explicitly maps the CSV identities for sellers
S01–S05 and products P01–P06: noodles, egg, dumpling, jelly drink, burger and lemon.
Unknown identities retain the existing product placeholder. Verified catalog
images take priority. No database product is created or inferred from these files.
